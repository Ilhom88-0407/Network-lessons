IPv6 asoslari IPv6 Basics

Asosiy atamalar
  • IPv6 — 128 bitli manzil, o‘n oltilik yozuvda
  • Global unicast — Internetda yo‘naltiriladigan yakka manzil
  • Link-local — faqat bitta kanal ichida amal qiladi (FE80::/10)
  • Anycast — bitta manzil, eng yaqin qurilma javob beradi
  • NDP — qo‘shnini aniqlash; IPv6 da ARP o‘rnini bosadi

1. Nega IPv6 kerak?

  • IPv4 — 32 bit, 1980-yillardan ishlaydi, manzil tugab bormoqda
  • sozlash noqulay · xavfsizlik va QoS yetarli emas
  • IPv6 (IPng) — IETF, 1990-yillardan; uzunlik 128 bit

1-rasm. 32 bit → 128 bit: manzil fazosi to‘rt barobar uzun

— 1 —

2. Manzil yozilishi

8 guruh, har biri 16 bit — 4 ta o‘n oltilik raqam, ikki nuqta bilan.

3. Manzil tarkibi

2-rasm. prefiks = tarmoq, interfeys ID = tugun (64 bit)

Mos kelishi: network ID → prefiks, host ID → interfeys ID, maska → prefiks uzunligi.

4. Manzil turlari

IPv6’da broadcast yo‘q — uning o‘rnini multicast bosadi.

9. Xotira kartasi

Xulosa

  • IPv6 — 128 bit, 8 guruh × 16 bit, o‘n oltilik
  • Qisqartirish: boshdagi nollar va bitta ::
  • Prefiks + interfeys ID (64 bit, EUI-64)
  • unicast · multicast · anycast; broadcast yo‘q
  • NDP: manzil aniqlash, router/prefiks topish, avtosozlash, DAD

Tekshirish

  1. IPv6 uzunligi? — 128 bit
  2. Link-local prefiksi? — FE80::/10
  3. :: necha marta ishlatiladi? — bir marta
  4. MAC o‘rtasiga nima qo‘shiladi? — FFFE
  5. RS va RA manzillari? — FF02::2 va FF02::1
