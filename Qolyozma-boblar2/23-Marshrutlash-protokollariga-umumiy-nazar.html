Marshrutlash protokollariga umumiy nazar Overview of Routing Protocols

Asosiy atamalar
  • Marshrutlanuvchi protokol — uzatiladigan ma’lumot protokoli, masalan IP
  • Marshrutlash protokoli — marshrutlarni topib beradi: RIP, OSPF, BGP
  • AS (avtonom tizim) — bitta boshqaruvdagi tarmoqlar guruhi
  • IGP / EGP — AS ichidagi / AS’lar orasidagi protokol
  • Masofa-vektor — qo‘shni aytgan masofaga ishonadi (RIP)
  • Kanal holati — butun topologiyani biladi, SPF hisoblaydi (OSPF)

3. Dinamik protokol qanday ishlaydi

Tarmoqdagi hamma router bir xil protokolni yuritishi kerak.

3-rasm. To‘rt qadam: topish → almashish → hisoblash → kuzatish

— 2 —
  • topish — o‘zini bevosita ulangan segmentlarda tanitadi
  • almashish — jadval qo‘shnidan qo‘shniga o‘tadi
  • hisoblash — algoritm next hop va metrikani beradi
  • kuzatish — davriy paket bilan nosozlik aniqlanadi
Sabab: har protokolning o‘z “tili” bor — turli protokol yuritgan routerlar bir-birini tushunmaydi.

Xulosa

  • Marshrutlash protokoli — hisoblaydi; marshrutlanuvchi (IP) — tashiydi
  • RIP — UDP 520 · OSPF — IP 89 · BGP — TCP 179
  • Ish tartibi: qo‘shnini topish → almashish → hisoblash → kuzatish
  • IGP (RIP, OSPF, IS-IS) — AS ichida; EGP (BGP) — AS’lar orasida
  • AS ID: 1–64511 ommaviy, 64512–65535 xususiy
  • D-V — Bellman-Ford; Link-State — Dijkstra, LSA va LSDB

Tekshirish

  1. OSPF protokol raqami? — 89, IP ustida
  2. RIP porti? — UDP 520
  3. BGP porti va turi? — TCP 179, EGP va D-V
  4. Xususiy AS raqamlari? — 64512–65535
  5. Link-State algoritmi? — Dijkstra (SPF)
