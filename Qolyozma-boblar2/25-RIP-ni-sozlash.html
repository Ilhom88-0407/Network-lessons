RIP ni sozlash Configuring RIP

Asosiy atamalar
  • network buyrug‘i — qaysi interfeyslarda RIP ishlashini belgilaydi
  • RIPv1 / RIPv2 — maskasiz / maskali, v2 — multicast 224.0.0.9
  • Silent interface — eshitadi, lekin yangilanish yubormaydi
  • Summary — avtomatik jamlash, undo bilan o‘chiriladi
  • Autentifikatsiya — yangilanishlarni parol/MD5 bilan himoyalash
  • display rip — protokol holati va taymerlarini ko‘rsatadi

1. Asosiy sozlash

[RTA]rip [ process-id ]
[RTA-rip-1]network network-address [ wildcard-mask ]
  • process-id yozilmasa — sukut bo‘yicha 1
  • wildcard-mask — maskaning teskarisi; network 0.0.0.0 — hamma interfeys
— 1 —

1-rasm. network — ham qaysi direct marshrut e‘lon qilinishini, ham qaysi interfeys paket olishini belgilaydi

2. Qo‘shimcha sozlashlar

[RTA-rip-1]silent-interface { all | interfeys }
[RTA-Eth1/0]rip split-horizon
[RTA-Eth1/0]rip poison-reverse

2-rasm. Jim interfeys yangilanish yubormaydi, lekin qabul qiladi

3. RIPv2 sozlash

[RTA-rip-1]version { 1 | 2 }
[RTA-rip-1]undo summary
[RTA-Ser2/0]rip authentication-mode md5 rfc2453 plain PAROL

3-rasm. undo summary — barcha subnetlar alohida e‘lon qilinadi

5-rasm. RTA jadvaliga 10.0.2.0/24 RIP orqali tushadi

RTA · RTBnetwork 10.0.0.0 · network 192.168.0.0
version 2 · undo summary
— 3 —

6. Holatni ko‘rish

6-rasm. display rip — versiya, summarizatsiya, taymerlar va tarmoqlar

  • debugging rip 1 packet — yuborilgan va olingan xabarlar
  • chiqishda: versiya, broadcast yoki multicast, manzil va cost

Xulosa

  • rip → network — RIP ni yoqishning ikki qadami
  • network e‘lon qilinmagan interfeys RIP dan tashqarida qoladi
  • silent-interface — yubormaydi, qabul qiladi
  • RIPv2: version 2 · undo summary · authentication-mode
  • Tekshirish: display rip · display ip routing-table · debugging

Tekshirish

  1. Sukutdagi process-id? — 1
  2. Hamma interfeysda yoqish? — network 0.0.0.0
  3. Avtosummarizatsiyani o‘chirish? — undo summary (faqat RIPv2)
  4. Qaysi rejimda autentifikatsiya? — interfeys rejimida
