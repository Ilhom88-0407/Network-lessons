Qurilma fayllarini boshqarish Network Device File Management

Asosiy atamalar
  • Boot fayl — Comware OS obrazi: .bin yoki .ipe
  • current-configuration — RAM dagi joriy sozlamalar
  • saved-configuration — flashda saqlangan konfiguratsiya
  • Savat — o‘chirilgan fayl vaqtincha turadigan joy

1. Fayl turlari va saqlash muhitlari

Qurilma barcha ma’lumotini fayl ko‘rinishida saqlaydi.

1-rasm. Uchta muhit: ROM · Flash (CF karta) · RAM

  • ROM — Boot ROM: ilovani izlab yuklaydi, buzilganda tiklaydi
  • Flash / CF — ilova, startup konfig va loglar; o‘chirilmaydi
  • RAM — ishlayotgan tizim va current-configuration
