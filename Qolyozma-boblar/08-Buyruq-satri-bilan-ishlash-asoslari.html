Xulosa

  • Kirish: console (mahalliy) · AUX · telnet 23 · SSH 22
  • View’lar ierarxik: user → system → interface / line / …
  • return yoki Ctrl+Z — istalgan joydan user view’ga
  • Buyruq turi: read · write · execution; rol: network-admin / operator / level-n
  • ? va Tab — yordam, ↑↓ — tarix, Space/Enter/Ctrl+C — sahifalash

Tekshirish

  1. SSH porti va telnet porti? — TCP 22 va TCP 23
  2. Console tezligi (default)? — 9600 bod
  3. Nechta VTY foydalanuvchi bir vaqtda? — 5
  4. VTY autentifikatsiya rejimlari? — none / password / scheme
