IP asoslari IP Fundamentals

Asosiy atamalar
  • IP manzil — qurilmaning tarmoqdagi manzili, 32 bit, 4 ta bayt
  • Tarmoq va host qismi — manzilning boshi — tarmoq, oxiri — qurilma raqami
  • Sinf (A/B/C) — manzil diapazoni: A — yirik, C — kichik tarmoqlar uchun
  • Broadcast — host qismi butunlay 1 — tarmoqdagi hammaga xabar
  • ARP — IP manzil bo‘yicha MAC manzilni topish protokoli
  • ICMP — xato va diagnostika xabarlari (ping shu protokolda)

1. Tarmoq sathi va IP

IP — TCP/IP tarmoq sathining asosiy protokoli, RFC 791. Ishonchsiz, ulanishsiz, best effort.

— 1 —
  • ARP — IP manzilni fizik (MAC) manzilga o‘giradi
  • RARP — fizik manzilni IP ga o‘giradi
  • ICMP — xato xabarlari, diagnostika · IGMP — multicast guruhlari
Qoida: IP paket ichini o‘qimaydi va holatini saqlamaydi. Ishonchlilik — TCP ning ishi.

Xulosa

  • 32 bitli IP = tarmoq raqami + host raqami
  • Sinflar: A 1–126 · B 128–191 · C 192–223 · D multicast · E zaxira
  • Sarlavha 20 bayt; TTL har routerda −1
  • Boshqa tarmoqqa — default gateway orqali
  • ARP: IP → MAC · RARP: MAC → IP · ICMP: xato va diagnostika

Tekshirish

  1. TCP va UDP protokol raqami? — 6 va 17
  2. Sarlavha uzunligi? — 20 bayt (Options’siz)
  3. 127.0.0.1 nima? — loopback
  4. Nega −2? — tarmoq va broadcast manzillari
  5. ARP so‘rov qanday ketadi? — broadcast, javob unicast
