Kommutator portlari xavfsizligi Port Security for Switches

Asosiy atamalar
  • 802.1X — port asosida foydalanuvchini tekshirish protokoli
  • Supplicant — kirmoqchi bo‘lgan mijoz (PC) dasturi
  • Authenticator — tekshiruvni o‘tkazuvchi kommutator
  • RADIUS server — parol va huquqlarni saqlovchi server
  • Port izolyatsiyasi — portlar o‘zaro gaplashmaydi, uplink ochiq

1. 802.1X — portda kirish nazorati

IEEE 802.1X — port asosida kirishni nazorat qilish (port-based access control), 2001-y.

  • 802.11 WLAN uchun ishlangan — endi simli LAN’da ham
  • tekshiruvdan o‘tmagan klient uchun port yopiq

1-rasm. Uchta rol: klient — kommutator — server

— 1 —
  • Supplicant — 802.1X klienti bor qurilma, EAPOL yuboradi
  • Authenticator — kommutator: portni ochadi yoki yopadi
  • Auth server — AAA: autentifikatsiya · avtorizatsiya · hisob
Yo‘nalish: klient ↔ kommutator — EAPOL, kommutator ↔ server — RADIUS.

2. Server: lokal yoki masofaviy

  • lokal — kommutator ichida; oz foydalanuvchi, ma’lumot tarqoq
  • masofaviy — alohida server; katta tarmoq, bitta baza

6. Izolyatsiyani sozlash

  • tizim: port-isolate group 1 — guruh yaratish
